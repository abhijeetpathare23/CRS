# Campus Recruitment System

A full-stack web application designed to streamline the recruitment process for students, recruiters, and administrators within a campus environment.

---

## 🚀 Features

### 👨‍🎓 Student Portal
- User registration & login
- View job openings
- Apply to jobs
- Track application status

### 🧑‍💼 Recruiter Portal
- Create and manage job postings
- View applicants for each job
- Shortlist or reject candidates

### 🛠 Admin Dashboard
- Approve users (students/recruiters)
- Manage all job listings and applications
- Monitor recruitment activity

---
